# Networking & the OSI Model

Teach the layers through bottom-up troubleshooting.

- Layer 1 (Physical): cables, link lights
- Layer 2 (Data Link): MAC addresses, ARP
- Layer 3 (Network): IP, routing (`ping`, `traceroute`)
- Layer 4 (Transport): TCP/UDP, ports (`netstat`, `ss`)
- Layer 7 (Application): DNS, HTTP, TLS (`dig`, `nslookup`)
